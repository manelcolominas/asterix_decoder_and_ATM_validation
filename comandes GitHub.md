### ABANS DE COMENÇAR A PROGRAMAR DE NOU SEMPRE FES UN:
```
git pull
```

### 1. QUAN VULGUIS PUJAR UN CANVI, UNA NOVA IMPLEMENTACIÓ O MODIFICAR UN FITXER:
```
git add .       # Aquesta commanda afegeix tots els canvis que s'han fet en tots els fitxers al commit.
```
### 2. TOT SEGUIT
```
git commit -m "<missatge del commit>"       # Dona-li un nom al commit, és obligatori.
```
### 3. I PER ÚLTIM
```
git push        # Puja els canvis al núvol
```
